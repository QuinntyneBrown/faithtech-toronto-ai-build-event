## Questions and defects

Search [existing issues](https://github.com/QuinntyneBrown/faithtech-toronto-ai-build-event/issues),
then open an issue with the affected commit, operating system, tool versions,
reproduction steps, expected result, actual result, and what you tried.
Use fictional event and participant data in examples and screenshots.
Feature proposals should explain the participant or administrator problem and
observable acceptance criteria.

Redact personal data and credentials. Report vulnerabilities through
[SECURITY.md](SECURITY.md). Contact your event organizer for entry codes,
registration, venue questions, or assistance with a deployed event.
Repository support depends on contributor availability; no response time is guaranteed.
