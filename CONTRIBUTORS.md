# Contributors

[Quinntyne Brown](https://github.com/QuinntyneBrown) maintains this repository.
Contributions include implementation, design, documentation, accessibility,
testing, reviews, and reproducible reports.

See the [contributor history](https://github.com/QuinntyneBrown/faithtech-toronto-ai-build-event/graphs/contributors)
or run `git shortlog -sn HEAD` locally. Issues and pull requests also record work
that does not appear in commit authorship. Request an acknowledgment by submitting
your preferred name, optional public profile, and a link to the contribution.
Obtain consent before adding another person's identifying information.

Start with [CONTRIBUTING.md](CONTRIBUTING.md). External assets and dependencies are
covered separately in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
